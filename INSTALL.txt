Snowline Garden | Public beta 0.1

1. 完整解压到可写文件夹，保留 Snowline-Patch.exe 旁边的 mod 文件夹。
2. 双击 Snowline-Patch.exe，选择自己已有的 Gardendless Windows 0.16.24 原版。
3. 选择一个全新的输出文件名。生成成功后运行该文件。
4. 公开版使用独立存档。首图古埃及按版本设计预置，之后靠游戏进度取得资源。

1. Extract the whole archive to a writable folder. Keep mod beside Snowline-Patch.exe.
2. Run Snowline-Patch.exe and select your own original Gardendless 0.16.24 Windows game.
3. Pick a new output filename. Launch the generated executable when the build is complete.
4. The beta starts its own save. Ancient Egypt is the starting map. Earn later progress through play.
