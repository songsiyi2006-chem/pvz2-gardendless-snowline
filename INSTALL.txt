装甲雪线与庭院工坊 0.2 · 铁血枭雄与噩梦
Snowline Garden 0.2 · Iron Tyrant and Nightmare

1. 完整解压补丁，保留同目录中的 mod 文件夹、compatibility.py、compatibility-data.json。
2. 双击 Snowline-Patch.exe，选择自己的原版 Windows 游戏，并为输出选择新的文件名。
3. 双击新游戏，默认保留进度。已有 0.1 档直接续玩；只有一个旧版来源自动复制全部栏位；两种来源并存时默认上一版雪线，可自行改选原版。
4. 在选择来源时按 Enter、Esc 都会继承。全新开始须再次点击确认，旧档保留在原处。不同机器或不同数据目录可使用原游戏的玩家存档导出、导入功能。

1. Extract all files together, including mod, compatibility.py and compatibility-data.json.
2. Open Snowline-Patch.exe, select your own Windows game and choose a new output filename.
3. Launch the generated game. Existing 0.1 saves resume directly. A single legacy source is copied automatically with all its player slots. With two sources, earlier Snowline is selected by default. You can choose the original game instead.
4. Enter or Escape in the source picker continues with your save. Starting fresh requires two explicit choices. Legacy saves stay in place. For different computers or game data folders, export and import through the original game's player screen.
